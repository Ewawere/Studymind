# StudyMind

**AI tutor that gets smarter about every student every day.**

Not a chat wrapper. Curriculum-aware, Learning-Brain driven tutoring built first for WAEC & JAMB students.

## Stack

- **Next.js 15** (App Router)
- **TypeScript**
- **Tailwind CSS v4**
- **Lucide icons**
- Mobile-first, dark mode by default

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Roadmap

This repo currently contains the landing page + app shell. More modules coming soon.
